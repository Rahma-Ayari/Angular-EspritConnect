Birthday Email

Envoie automatiquement un email le jour de l'anniversaire des utilisateurs.

{{ settings.active ? 'Activé' : 'Désactivé' }} Dernier envoi : {{ settings.lastRunAt | date:'dd MMM yyyy' }}

L'email sera envoyé chaque jour à cette heure pour les utilisateurs dont c'est l'anniversaire.

Utilisez {{nom}} pour insérer le prénom du destinataire.

Comment ça fonctionne
  • Le scheduler vérifie chaque jour à l'heure configurée.
  • Les utilisateurs dont c'est l'anniversaire reçoivent l'email.
  • Utilisez {{nom}} dans le template pour personnaliser.
  • Désactivez le toggle pour suspendre les envois.
